# Sarvodaya Pre-University College Website

A premium, professional website for Sarvodaya Pre-University College built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Features

- **Premium Design**: Editorial layout inspired by high-end Framer websites
- **Responsive**: Fully responsive design for all screen sizes
- **Animations**: Smooth animations using Framer Motion
- **Modern Tech Stack**: React 18, TypeScript, Vite, Tailwind CSS
- **Sections**: Hero, About, Programs, Integrated Coaching, Results, Campus, Gallery, Admissions, FAQ, Contact, Footer

## Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Project Structure

```
src/
├── components/       # Reusable components (Navbar, Footer)
├── sections/         # Page sections (Hero, About, Programs, etc.)
├── data/            # Content data (collegeInfo, programs, faqs, etc.)
├── main.tsx         # Application entry point
├── App.tsx          # Main app component
└── index.css        # Global styles
```

## Content

All college information is sourced from the official Sarvodaya PUC website (sarvodayapuc.com). The website includes:

- Science programs (PCMB, PCMC) with NEET/JEE/KCET coaching
- Commerce programs (CEBA, SEBA) with CA Foundation and CS coaching
- Admission process and enquiry form
- Contact information and location
- FAQ section

## Design Philosophy

The website follows a premium editorial design approach:
- Sophisticated color palette (navy, ivory, gold)
- Premium typography (Playfair Display for headings, Inter for body)
- Generous whitespace
- Cinematic image treatment
- Subtle, intentional animations
- Mobile-first responsive design

## Performance

- Optimized for fast loading
- Lazy loading for images
- Code splitting
- SEO optimized
